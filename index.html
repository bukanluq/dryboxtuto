Setup steps

  1. Create a Supabase project

    Sign up at supabase.com (free) and create a new project.

    Then open Storage, create a bucket named item-photos, and turn Public bucket on.

  2. Create the database tables

    Open SQL Editor in Supabase, paste in the contents of the Supabase Setup file, and press Run.

    Starting over? Run the Supabase Reset file first, then run Setup again.

  3. Copy your project keys

    Go to Project Settings → API and copy two values: the Project URL and the anon public key. You'll paste them into two files.

  4. Install the Arduino tools

    Install Arduino IDE, then add the ESP32 board package: in Preferences, add this to Additional Boards Manager URLs, then install esp32 from Boards Manager.

    https://espressif.github.io/arduino-esp32/package_esp32_index.json

    In Library Manager install: DHT11 (by dhrubasaha08) and LiquidCrystal I2C (by Frank de Brabander).

  5. Upload the ESP32 code

    Open the ESP32 file in Arduino IDE. Near the top, paste your Project URL and anon key between the quotes. Choose your ESP32 board and port, then upload.

  6. Connect the device to WiFi

    On your phone, join the WiFi named ESP32-Setup-XXXXXX, then open 192.168.4.1 in a browser. Pick your WiFi, enter its password, and save.

    The device restarts and shows its Device ID (6 characters) on the LCD. Write it down.

  7. Set up the web app

    Open the Web App file, paste the same Project URL and anon key near the top of the script, then save the file as index.html.

    Upload it to a free host such as Vercel, or just open it on your computer.

  8. Register your device

    In the web app tap Register, enter a name, the Device ID from step 6, and an optional photo. Then tap Check — you should see Online with live humidity.

Tip: If the device ever can't join WiFi, it opens the ESP32-Setup network again by itself so you can pick a new one. To clear a saved WiFi on purpose, visit the device's local page and choose "Forget WiFi".
